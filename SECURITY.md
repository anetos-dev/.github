# Security policy

Please don't report a vulnerability in a public issue, discussion or
pull request. Report it privately with the "Report a vulnerability"
button of the repository's Security tab; for the framework, use
[the framework's private report form](https://github.com/anetos-dev/anetos/security/advisories/new).

The framework's [security policy](https://github.com/anetos-dev/anetos/blob/main/SECURITY.md)
says what happens next, which versions get fixes, and what is in scope.
The other repositories follow the same process.
