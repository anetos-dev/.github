# anetos-dev/.github

The organization's shared files. GitHub shows the community files below
in every repository of [anetos-dev](https://github.com/anetos-dev) that
has none of its own, and `profile/README.md` on the organization's page:

| File | What |
|---|---|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | The code of conduct: Contributor Covenant 3.0 |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Which repository a contribution belongs in |
| [SUPPORT.md](SUPPORT.md) | Where to ask a question |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability |
| [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE) | The issue forms of the repositories without their own (anetos has its own) |
| [profile/README.md](profile/README.md) | The organization's page on GitHub |

A repository's own file of the same kind replaces the default here.
