# Contributing to Anetos

Thank you for helping. Each repository takes its own kind of change:

| To change | Go to | Its guide |
|---|---|---|
| The framework, the CLI, the drivers, the plugins, the examples, or a page of docs.anetos.dev | [anetos-dev/anetos](https://github.com/anetos-dev/anetos) | [CONTRIBUTING.md](https://github.com/anetos-dev/anetos/blob/main/CONTRIBUTING.md) |
| A translation of the framework's messages, or a new language | [anetos-dev/locales](https://github.com/anetos-dev/locales) | [Adding or fixing a language](https://github.com/anetos-dev/locales#adding-or-fixing-a-language) |
| The docs site's look, navigation or build (not its pages) | [anetos-dev/docs](https://github.com/anetos-dev/docs) | Its README |
| anetos.dev, the home page | [anetos-dev/website](https://github.com/anetos-dev/website) | Its README |

For anything bigger than a fix, open an issue first, so the design is
agreed before the code is written. Questions go to
[Discussions](https://github.com/anetos-dev/anetos/discussions).

Everyone follows the [code of conduct](CODE_OF_CONDUCT.md). What you
send is licensed under the repository's license, Apache 2.0, as its
section 5 says: there is no contributor license agreement and no
sign-off. [GOVERNANCE.md](https://github.com/anetos-dev/anetos/blob/main/GOVERNANCE.md)
says how decisions are made.
